# MONIRESH — MVP SCOPE
> Phase 5 | Must / Should / Could / Won't

## Must Have (V1 ship)
- Auth (email/pass + Google OAuth via Supabase)
- Projects CRUD + switching
- Search Builder (keywords, boolean, DB-specific)
- Paper collection: OpenAlex + Semantic Scholar + Crossref + upload RIS/BibTeX/CSV/PDF
- Deduplication engine
- Screening with audit trail + PRISMA
- Full-Text Analyzer (decompose paper)
- Evidence Matrix + export
- GapFinder + Verification + Novelty Score (0-100)
- Synthesis Agent
- Manuscript workspace (Tiptap) with citation pills + Evidence Canvas
- Citation Guardian + Reference Manager (DOI → Crossref → APA7)
- Research Quality Score

## Should Have (V1.1)
- Retraction checker
- Reference freshness
- Bibliometrics
- Cover letter generator

## Could Have (V2+)
- Data Analysis Python engine
- Journal Matchmaker deep
- Collaboration + comments + supervisor view

## Won't Have (V1)
- Native mobile app, offline desktop, full meta-analysis stats, plagiarism DB (integrate external license later), automatic Scopus/WoS without user subscription, "humanizer to bypass AI detector" (we do Academic Voice Editor instead)
